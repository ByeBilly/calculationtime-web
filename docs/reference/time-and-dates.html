Time and dates endpoints

Date and time calculations over plain JSON. Local time takes a latitude and longitude; date routines take ISO dates and return explicit, inspectable results rather than a bare number.

Request bodies below are the examples published in the API's OpenAPI contract. The contract declares body fields only as free-form JSON, so it does not say which fields are required or optional; treat each example as a known-good shape and read the result's fields. Replace YOUR_KEY with a beta key; never put a key in public code. Endpoints marked public work as shown with no key.

GET /v1/time

Get local time for one coordinate.

API key required1 credit

Parameters: lat (query), lon (query), at (query)

curl 'https://api.calculationtime.com/v1/time?lat=48.137154&lon=11.576124&at=2026-07-29T12:00:00Z' \
  -H 'X-API-Key: YOUR_KEY'

Other responses in the contract: 400 invalid input, 401 missing or invalid key, 402 credits exhausted, 403 account suspended or trial expired, 429 rate limited.
