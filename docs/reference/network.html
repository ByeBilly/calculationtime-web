Network and web utilities endpoints

Small deterministic web-developer utilities. They are API-key protected in this contract unless explicitly listed as public elsewhere; use them server-side or in private tooling, not with keys embedded in public browser code.

The contract declares body fields only as free-form JSON, so it does not say which fields are required or optional; treat each example as a known-good shape and read the result's fields. Replace YOUR_KEY with a beta key; never put a key in public code. Endpoints marked public work as shown with no key.

POST /api/v1/network/ip-parse

Parse IPv4 or IPv6 address metadata.

API key required1 credit

curl -X POST 'https://api.calculationtime.com/api/v1/network/ip-parse' \
  -H 'X-API-Key: YOUR_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"ip":"192.168.1.10"}'

Other responses in the contract: 400 invalid input, 401 missing or invalid key, 402 credits exhausted, 403 account suspended or trial expired, 429 rate limited.
