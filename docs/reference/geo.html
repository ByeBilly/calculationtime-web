Geo endpoints

Geospatial helpers that work from coordinates you supply. Distances are great-circle distances on a sphere; treat them as estimates, not survey-grade values.

6 operations · contract v0.1.0 · base URL https://api.calculationtime.com

Request bodies below are the examples published in the API's OpenAPI contract. The contract declares body fields only as free-form JSON, so it does not say which fields are required or optional; treat each example as a known-good shape and read the result's fields. Replace YOUR_KEY with a beta key; never put a key in public code. Endpoints marked public work as shown with no key.

GET /v1/geo/distance

Distance between two coordinates.

API key required1 credit

Parameters: lat1 (query), lon1 (query), lat2 (query), lon2 (query)

curl 'https://api.calculationtime.com/v1/geo/distance?from_lat=48.137154&from_lon=11.576124&to_lat=52.52&to_lon=13.405' \
  -H 'X-API-Key: YOUR_KEY'

Other responses in the contract: 400 invalid input, 401 missing or invalid key, 402 credits exhausted, 403 account suspended or trial expired, 429 rate limited.

POST /v1/geo/distance/batch

Batch distance calculations.

API key required1 credit

curl -X POST 'https://api.calculationtime.com/v1/geo/distance/batch' \
  -H 'X-API-Key: YOUR_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"pairs":[{"from":{"lat":48.137154,"lon":11.576124},"to":{"lat":51.5072,"lon":-0.1276}}]}'

Other responses in the contract: 400 invalid input, 401 missing or invalid key, 402 credits exhausted, 403 account suspended or trial expired, 429 rate limited.
