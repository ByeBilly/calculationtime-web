Service and status endpoints

The service endpoints need no key. They tell you whether the API is up, what it exposes and what time the server believes it is. Use them for health checks and for discovering the contract.

The contract declares body fields only as free-form JSON, so it does not say which fields are required or optional; treat each example as a known-good shape and read the result's fields. Replace YOUR_KEY with a beta key; never put a key in public code. Endpoints marked public work as shown with no key.
