CalculationTime API endpoint reference

Every documented operation in the CalculationTime API contract (v0.1.0), grouped by area, with a copy-paste request for each. 105 operations across 10 areas. Reference data and service probes are public; everything else needs a beta key.

  • Service and status7 operations. Public probes: health, status, the OpenAPI contract and a UTC clock.
  • Reference data11 operations. Public JSON tables: countries, time zones, elements, constants, materials, HTTP status, MIME types, Unicode blocks, constellations, bright stars, meteor showers.
  • Time and dates20 operations. Local time for a coordinate, date differences, date arithmetic, business days, ISO weeks, ages, epoch conversion and more.
  • Geo6 operations. Great-circle distance, midpoint, bounding box and elevation for latitude and longitude points.
  • Astronomy and Crux clock15 operations. Sun and moon position, twilight, sidereal time, Julian date, ephemeris, and the Crux Sky Clock engine.
  • Finance14 operations. Loan amortization, simple and compound interest, ROI, CAGR, margin, markup, break-even, discounts and sales tax.
  • Math and statistics16 operations. Quadratics, triangles, circles, proportions, logarithms, exponents, percentages, combinatorics and statistics summaries.
  • Health5 operations. BMI, BMR, TDEE, macro splits and pace, with the formula named in the result.
  • Payroll and trades7 operations. Decimal hours, job margin, mileage claims, tool depreciation, invoice aging and VAT summaries.
  • Account4 operations. Credit balance, usage and plan limits for the key you call with.

New to the API? Start with the developer guide. Administrative and private-sharing routes are deliberately left out of this reference.
